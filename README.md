# Role-Based Login System

This is a full-stack Role-Based Authentication project built using:

- ASP.NET Core Web API
- Angular
- JWT Authentication
- Role-Based Authorization (Admin/User)

## Project Structure

MainFolder/
- RoleBasedLoginSln  → .NET Core API
- RoleBasedCli       → Angular Application

## Features

- User Registration & Login
- JWT Token Generation
- Role-based access control
- Protected APIs
- Angular login and dashboard

## Technologies Used

- .NET 8 Web API
- Angular
- Entity Framework Core
- SQL Server
- JWT Authentication
